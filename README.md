# Data Structures and Algorithms

A personal repository for learning, practicing, and documenting Data Structures and Algorithms using Java.

This repository contains my implementations of DSA concepts, problem-solving approaches, and practice problems as I progress through my DSA preparation.

## Learning Resource

I am primarily following **Striver's A2Z DSA Sheet by takeUforward** as the roadmap for my DSA preparation.

The A2Z DSA Sheet provides a structured progression from programming fundamentals and basic problem solving to advanced Data Structures and Algorithms topics.

Resource:

- [Striver's A2Z DSA Sheet](https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet)

The roadmap covers topics including:

- Programming Fundamentals
- Time and Space Complexity
- Arrays
- Sorting
- Hashing
- Binary Search
- Strings
- Recursion
- Linked Lists
- Bit Manipulation
- Greedy Algorithms
- Sliding Window and Two Pointers
- Stack and Queue
- Binary Trees
- Binary Search Trees
- Heaps
- Graphs
- Dynamic Programming
- Tries
- Advanced String Algorithms
- Mathematics

The goal is to understand the underlying problem-solving patterns rather than simply memorizing solutions.

## Language

All implementations in this repository are primarily written in:

- Java

Java is being used to strengthen my programming fundamentals and prepare for technical interviews and competitive problem solving.
